# The IANA timezone database, as a package.
#
# NOT optional here. The schedule engine converts between the user's
# Asia/Dhaka wall-clock times and UTC, and `zoneinfo` reads the system tz
# database — which Windows does not ship. Without this, ZoneInfo("Asia/Dhaka")
# raises ZoneInfoNotFoundError on any Windows machine. Linux CI has a system
# copy at /usr/share/zoneinfo, so this failure is invisible in GitHub Actions
# and only appears on a developer's PC — which is exactly the kind of
# "works on CI, broken locally" gap that costs hours to find.
tzdata==2026.4
